## 🧠 개념 (정확한 정의)

👉 학생의 학습 데이터를 분석해서  
👉 **학습 상태·성과·이탈·취약점 등을 예측/진단하는 사업**

---

## 📊 실제 사업 구조 (현실)

### ✔ 기본 구성

1. 데이터 수집
    - LMS 로그
    - 문제풀이 결과
    - 출결 / 과제
2. 데이터 통합
    - 학습 이력 통합 DB
    - 데이터 허브
3. AI 분석
    - 성취도 예측
    - 중도탈락 예측
    - 학습 패턴 분석
4. 시각화 / 서비스
    - 교사용 대시보드
    - 정책 분석 리포트

---

## 📌 실제 사례 구조

- 대학/기관에서 **AI 학습행태 분석 + 예측 시스템 구축**
- 학생 학습패턴 기반으로 학업 지속 요인 분석

👉 핵심  
👉 “데이터 → 예측 → 정책 활용”

---
