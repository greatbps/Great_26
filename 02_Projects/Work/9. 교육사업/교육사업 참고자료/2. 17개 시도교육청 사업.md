# 🔥 2026년 시도교육청 “신규 과제형 사업” 핵심 리스트

## ① AI 교육 / 디지털 전환 실증 사업 (최우선)

👉 거의 모든 교육청 공통 추진

### 주요 내용

- AI 기반 학습 분석 시스템
- 디지털 교과서 / AI 튜터 실증
- 학생 맞춤형 학습 추천

### 발주 형태

- 연구용역 + 실증사업 (혼합형)
- 금액: 2억 ~ 15억

### 특징

- 신규 업체 진입 매우 쉬움 ⭐
- 기존 SI 업체 영향력 낮음

👉 **실제 목표**  
→ 실증 후  
→ “전면 도입 SI 사업”으로 확장

## ② 교육데이터 통합·분석 과제 (초핵심)

👉 이건 무조건 들어가야 한다

### 주요 내용

- 학생 학습이력 데이터 통합
- 학교별 데이터 수집/표준화
- 데이터 기반 정책 분석

### 발주 형태

- 데이터 구축 + 분석 연구
- 3억 ~ 20억

### 특징

- 한국교육학술정보원 연계 사업 많음
- 향후 “데이터 플랫폼 SI”로 100% 이어짐

👉 **핵심 포인트**

- RAG / 데이터레이크 / AI 분석  
    → 여기서 강하게 먹힘

## ③ 디지털 교실 / 스마트 학습환경 구축 (파일럿형)

👉 “작게 시작 → 크게 터지는 사업”

### 주요 내용

- 스마트 교실 구축
- LMS + 콘텐츠 플랫폼
- 협업 학습 환경

### 발주 형태

- 시범학교 중심 구축
- 5억 ~ 30억

### 특징

    → 대신 **컨소시엄으로 진입 가능**

👉 **중요**  
→ 이후 교육청 전체 확산됨 (대형 SI)

# 💡 진짜 중요한 전략 (핵심)

## 1️⃣ “연구과제처럼 보이지만 SI다”

거의 모든 과제가:

👉 1단계: 연구/실증  
👉 2단계: 시스템 구축 (대형 SI)

---

## 2️⃣ 무조건 초기 과제 들어가야 하는 이유

- 기존 SI 업체 없음
- 기술 평가 중심
- 관계 형성 가능

👉 한 번 들어가면  
→ 다음 사업 자동 초대 구조

---

## 3️⃣ 가장 먹기 좋은 포지션

👉 “AI + 데이터 플랫폼 전문 업체”

이렇게 포지셔닝 해라:

- 학습데이터 분석
- AI 기반 교육지원
- 데이터 통합 아키텍처

---

## 4️⃣ 현실적인 진입 전략 (중요)
