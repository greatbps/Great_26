# 유지보수 + 기능개선 사업 구조

ATCIS는 보통 **2개의 사업으로 나뉜다.**

### 1️⃣ 기반체계 유지보수

- 서버
- 전술 단말
- 네트워크 장비
- 운영지원

→ 약 **60억**

### 2️⃣ 개발SW 기능보강

- UI 개선
- DB 성능 개선
- 보안 패치

→ 약 **20~30억**

즉 실제 **연간 ATCIS 유지보수 시장**

👉 **약 80~90억 규모**

---

# 중요한 포인트 (사업 전략)

ATCIS 유지보수 특징

1️⃣ **대기업 참여 제한 (중소 SW 사업)**  
2️⃣ **중견 SI + 방산업체 컨소시엄**  
3️⃣ **한번 들어간 업체가 계속 반복 수주**

그래서 실제 시장은

쌍용정보통신  
대보정보통신  
**진두아이에스**

---
# 1️⃣ 육군 C4I 유지보수 소요군 (핵심)

### ① 정책 / 소요 제기

👉 육군본부

- **정보화기획참모부 (G-6 계열)**
- **지휘통제체계 담당 부서**
    

역할

- C4I 체계 소요 제기
- 기능개선 요구
- 성능개량 요구

즉 **ATCIS 유지보수 소요의 최상위 부서**다.

---

### ② 체계 운영 담당

👉 육군 지능정보기술단

여기가 **실질적인 운영 부대**다.

역할

- ATCIS 체계 운영
- 유지보수 요구사항 관리
- 장애 대응
- 운영 환경 관리
- 기능 개선 요청
    

실제 유지보수 사업에서 **업체와 가장 많이 접촉하는 조직**이다.

---

### ③ 사업 관리 / 발주

👉 한국국방연구원 (KIDA)

역할

- 유지보수 사업 발주
- 사업관리(PMO)
- 사업 평가

즉 구조는 보통 이렇게 된다.

육군본부 (소요 제기)  
     ↓  
육군 지능정보기술단 (운영 요구)  
     ↓  
한국국방연구원 KIDA (사업 발주)  
     ↓  
민간 업체 (유지보수 수행)

---

# 2️⃣ 실제 운용 부대 구조

ATCIS는 육군 전체에서 운용된다.

주요 운용 제대

- 군단
- 사단
- 여단
- 포병부대
- 감시정찰부대

하지만 **유지보수 통합 창구는 대부분 지능정보기술단**이다.

---

# 3️⃣ 사업 관점에서 중요한 조직

제안 준비할 때 실제 영향력 있는 조직은 이 세 곳이다.

1️⃣ 육군본부  
→ 정책 / 소요 결정

2️⃣ 육군 지능정보기술단  
→ 실 운영 / 요구사항

3️⃣ 한국국방연구원  
→ 사업 발주
