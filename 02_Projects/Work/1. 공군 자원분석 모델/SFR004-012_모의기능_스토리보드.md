# Ⅲ-2. 기능요구사항 스토리보드 (라~타, SFR-004~012)

**적용 템플릿**: 육군 자원소요분석모델 제안서 분석 결과 —
`[1/3] 모의기능식별→모의개념→모의절차(예시)` → `[2/3] 모의기능 흐름도→기초자료 편집→작전계획(입력자료) 작성` → `[3/3] 상세 로직(수리식)→모의결과 자료(안)`

**이번에 강제로 채워 넣는 5요소** (기존 목차에 빠져 있던 부분):
① 수리식(정량 산정식) ② STORM 자료 입력방안 ③ KAFARAM 연동 ④ 국방자원관리체계 연동 ⑤ BORAME 기능개선·통합

각 항목마다 이 5요소 중 **해당되는 것만** 상세로직 파트에 명시적으로 박아 넣었습니다(억지로 8개 항목 전부에 5개를 다 넣지 않음 — 육군 제안서도 항목별로 필요한 서브 그림만 골라 썼던 것과 같은 원칙).

## 라. 모의기능 개발 (SFR-004) — ★핵심 차별화 항목

### [1/3] 모의기능식별 → 모의개념 → 모의절차(예시)

**모의기능식별(RFP 요구사항)**
| 구분 | 세부요구사항 |
|---|---|
| RFP(SFR-004) | 특수전부대·화학탄·드론에 의한 피해율을 전시 보충소요에 반영하기 위한 신규 모의기능 개발 |
| RFP(SFR-004②) | 특수전부대: 기지강습/지상침투 구분, 근접·원거리 공격 구분, 아 방어전력과의 교전모의 |
| RFP(SFR-004③) | 화학탄: 피해율 모의방안 제시 |
| RFP(SFR-004④) | 드론: 공격형태별 구분 피해율 모의 |
| RFP(SFR-004⑤) | 모의결과의 6대 자산 반영방안 |

**모의개념**
- STORM이 모의하지 못하는 3대 위협(특수전부대·화학탄·드론)의 피해율을 신규 산정식으로 계산하여, STORM 전투손실 결과에 **추가 보정치**로 합산
- 전투모의(교전 시뮬레이션)가 아니라 **"침투/공격 시나리오 입력 → 피해율 산정식 → 결과값 출력"** 구조의 결정형 계산

**모의절차(예시)**
```
시작 → [위협유형 선택: 특수전부대/화학탄/드론]
     → [기초자료 입력: 침투조수·확산조건·드론제원]
     → [피해율 산정식 적용]
     → [6대 자산 반영(원인별 태깅)]
     → 종료
```

### [2/3] 모의기능 흐름도 → 기초자료 편집 → 작전계획(입력자료) 작성

**모의기능 흐름도**
```
기초자료 편집 → 위협 시나리오 입력 → [피해율 산정 엔진] → 6대자산 반영 → 결과분석/자료제공
```

**기초자료 편집**
- 아 기지 방어전력 자료: 초소 밀도, 기동타격대 배치, 경계강도
- 화학탄 확산 기초자료: 대기확산모델 계수(풍향·풍속·대기안정도 참고값)
- 드론 제원 DB: 탄두중량, 속도, 고도, 요격체계 대응시간
- **JWS(합동무기소요체계) 무장효과 DB** — 드론 탄두를 유사 등록무장으로 등가 환산하기 위한 참조자료(BORAME가 이미 JWS 연동 방식으로 피해산출을 하고 있으므로 그 방식을 그대로 재사용)

**작전계획(시나리오) 입력자료**
- 침투조 편성(특수전부대 규모·침투경로: 기지강습/지상침투)
- 화학탄 사격계획(작용제 종류, 사격량, 표적기지)
- 드론 공격계획(공격형태, 파상 횟수)

### [3/3] 상세 로직(수리식) → 모의결과 자료(안)

**상세 로직 — ①수리식 / ⑤BORAME 기능개선·통합**

```
[특수전부대 피해모형]
기지강습피해 = 침투조수 × 성공확률(방공망돌파) × 목표당_평균파괴력 × (1−아방어전력_저지율)
지상침투피해 = 침투조수 × 접근성공확률(지형·경계밀도) × 원거리사격_피해기대값
아방어전력_저지율 = f(초소밀도, 기동타격대 대응시간, 경계강도)

[화학탄 피해모형]
화학피해율(지점,t) = 확산모델(풍향,풍속,기온,지형) × 표적별_노출시간 × 표적유형별_취약도
강화시설(엄체·지하시설)_화학피해 = 0   ※BORAME "강화시설물은 공중/지상공격에 피해 없음" 면역로직 그대로 계승

[드론 피해모형]
드론피해율 = Σ_드론유형[ 침투성공확률(대드론요격률 반영) × JWS보간_피해율(탄두중량 등가환산) ]
※ BORAME의 "무기별·각도별·거리별 피해산출 격자 + 선형보간" 방법론을 드론에 그대로 확장 적용
  → 신규 무장효과 DB를 별도로 구축할 필요 없이 기존 JWS 자산 재사용(개발기간·리스크 축소 = USP)
```

**모의결과 자료(안)**
- 위협유형별 피해율(%) 및 피해량(대수/인원)
- 6대 자산 반영 태그(원인코드: 특수전/화학/드론/기타)

## 마. 장비(항공기) 소요 산정 (SFR-005)

### [1/3]
**모의기능식별**: 전투손실(적공격 공대공·지대공·특수전) + 비전투손실(비행사고) 구분 산정, 일자별/작전단계별/기종별/기지별 산출

**모의개념**: STORM 모의결과(항공기 손실·기종별 소티)를 입력요소로, 항공기 상태전이(정상→경정비→전투손상→손실)에 따라 보충소요를 계산

**모의절차(예시)**: `STORM 손실자료 입력 → 전투/비전투 손실 분리 → 일자·기종·기지별 집계 → 소요 산출`

### [2/3]
**흐름도**: `STORM 결과 입력 → 원인별 분리 계산 → 소요산정 → 결과제공`

**기초자료 편집**
- ②**STORM 자료 입력방안**: STORM 산출물(csv/xml/xls)의 "기종별 손실량/손실률", "기종별 전시 임무 및 소티" 필드를 자동 매핑하여 목표체계 DB로 적재(SFR-003 준비단계에서 이미 구축한 자동변환 파이프라인 재사용)
- 항공기 취약면적·Kill전이확률 참조표(§라 피해모형과 연동)

**작전계획(입력자료)**: 기종별 사고율(연간), 기상조건별 가동률

### [3/3]
**상세 로직(①수리식)**
```
전투손실(t) = Σᵢ 출격소티(i,t) × 피격확률(i,t) × Kill전이확률(무장유형,교전거리,각도)
비전투손실(t) = 가동소티(t) × 기종별_사고율(연간사고율/365) × SF_기상
```
- 피격확률은 STORM 교전결과(공대공/지대공/특수전 구분)에서 인계, Kill전이확률은 §라의 JWS 보간모형 재사용

**모의결과 자료(안)**: 일자별/작전단계별/기종별/기지별 항공기 소요표, 원인별(격추·사고) 분리 집계

## 바. 장비(작전지원장비) 소요 산정 (SFR-006)

### [1/3]
**모의기능식별**: 전투손실(적 항공기·TBM 공격) + 비전투손실(내용년수·결함) 구분

**모의개념**: 노천 배치장비는 시설피해모형(등가원 면적)으로, 엄체 내 장비는 면역 처리하여 산정

**모의절차(예시)**: `STORM/BORAME 피해자료 입력 → 배치위치(노천/엄체) 판정 → 손실 산출`

### [2/3]
**흐름도**: `기초자료(배치현황) 편집 → 피해자료 연동 → 손실 산정 → 결과제공`

**기초자료 편집**: 기지별 장비 배치현황(노천/엄체 구분), 장비별 내용년수·결함율

**작전계획(입력자료)**: 전구급 아 부대 피해(항공침투·TBM) 현황 — STORM 인계

### [3/3]
**상세 로직 (①수리식 / ⑤BORAME 기능개선·통합)**
```
전투손실(t) = Σ_기지[ 노천배치장비(기지) × 등가원피해율(기지,t) ]
            + Σ_기지[ 엄체보관장비(기지) × 강화시설면역계수(=0) ]
비전투손실(t) = 보유량 × (1/내용년수) × (Δt/365) + 결함율(장비유형)
```
- **등가원피해율**: BORAME의 "길이L·너비W 시설 → R=√(LW/π) 등가원 환산 후 피해율(%) 산정" 로직을 노천 배치구역에 그대로 적용(계승)
- **강화시설 면역계수=0**: BORAME "강화시설물(엄체호 등)은 공중/지상공격에 의한 피해 없음" 로직 그대로 이식 → 이 부분이 **BORAME 기능 고도화·통합의 핵심 증거**로 제안서에 명시할 지점

**모의결과 자료(안)**: 일자별/작전단계별/기능별/기종별/기지별 장비 소요표

## 사. 인원 소요 산정 (SFR-007) — BORAME 미보유, 완전 신규 개발

### [1/3]
**모의기능식별**: 전투손실(전사·중상·실종·포로)/비전투손실(질병·사고·탈영) 구분, 계급·병과·기지별 산출, **특수전부대 피해 포함**

**모의개념**: BORAME는 시설·항공기 피해만 다루고 인명피해 모형이 없으므로, 시설피해율에 인원배치밀도를 연동한 **신규 기대손실모형**을 개발

**모의절차(예시)**: `시설피해율 + 특수전 교전결과 입력 → 인명노출계수 적용 → 인원손실 산출`

### [2/3]
**흐름도**: `기초자료(편제인원) 편집 → 피해연동 → 노출계수 적용 → 손실 산정`

**기초자료 편집**: 기지별 편제인원(계급·병과), 시설별 재직 인원밀도, 방호시설 수용률

**작전계획(입력자료)**: 임무수행 중 항공기 피해, 아 부대 피해(항공침투·TBM), **특수전부대에 따른 피해**(§라에서 인계)

### [3/3]
**상세 로직(①수리식)**
```
전투손실인원(t) = Σ_기지[ 시설피해율(기지,t) × 배치인원(기지,병과) × 인명노출계수(K_exp) ]
                + 특수전부대_교전손실인원(§라에서 인계)
                + TBM_피해인원(등가원모형 × 인구밀도)
비전투손실인원(t) = 편제인원 × 일일기저손실률(질병·사고) × (1+전시스트레스계수×작전강도)
```
- K_exp(노출계수): 엄체 여부·근무형태(옥외/옥내)별 0~1 — BORAME의 "강화시설 면역" 개념을 인명피해에 맞게 **확률적으로 완화 적용**한 것이 신규개발 포인트

**모의결과 자료(안)**: 일자별/작전단계별/기지별/계급·병과별 인원 소요표

## 아. 탄약 소요 산정 (SFR-008) — KAFARAM 준용

### [1/3]
**모의기능식별**: 탄종별(공대공/공대지/일반폭탄/특수목적탄/방공유도탄/기타탄약) 구분, **KAFARAM 기능 준용**, 전시 365일 기준 일자별·단계별 산출, 3군 공통탄약 소요량 포함

**모의개념**: STORM 모의결과(항공기 손실, 기종별 소티, 격추수/율)를 입력요소로, **KAFARAM의 탄종별 소모량(율) 판단 로직**을 그대로 준용하여 계산

**모의절차(예시)**: `STORM 결과+KAFARAM 소모율 입력 → 탄종별 산정 → 일자·단계별 누적`

### [2/3]
**흐름도**: `기초자료(무장추천목록) 편집 → KAFARAM 연동 → 탄종별 산정 → 결과제공`

**기초자료 편집**
- ③**KAFARAM 연동**: "STORM, KAFARAM 모의운영결과를 참고하여 공대공/공대지/지대공/기타 무장의 소모량(율)을 판단"(제안전략.txt 원문 반영) — KAFARAM 산출물의 탄종별 소모율(율) 필드를 목표체계 입력요소로 직접 매핑
- 敵아 격추비 기준표(예: 항공공격 7:지대공3), 무장추천목록, 고정표적(JDPI) 목록

**작전계획(입력자료)**: 육군 공통탄약 소요량(3군 공통탄약 항목), 기상조건별 소티·무장세트

### [3/3]
**상세 로직(①수리식 / ③KAFARAM 연동)**
```
탄종별소모량(t) = Σ_기종[ 소티수(기종,t) × 무장탑재량(기종,탄종) × 명중률가정 ]
                 + 대공방어_소모량(지대공유도탄, 요격시도횟수 × 발사기준)
탄종별기간소요(t~t+Δ) = Σ 탄종별소모량 − 기보유량 + 안전재고계수 × 예상소모율
```
- 명중률가정·소모율(율) 파라미터는 **KAFARAM 결과값을 준용**(신규 추정 없이 검증된 값 재사용 = 리스크 최소화 USP)

**모의결과 자료(안)**: 일자별/단계별/탄종별 소모량, 전(前)연구 대비 비교결과표, 3군 공통탄약 소요량

## 자. 유류 소요 산정 (SFR-009) — 완전 신규 개발

### [1/3]
**모의기능식별**: 비행연료/윤활유/정비연료 소요 및 손실 구분, 일자별/작전단계별/유종별/기지별/기종별/원인별 산출

**모의개념**: 소티 기반 소모량 산정 + 저장시설 피해(§라·§바 모형 재사용)에 의한 손실 산정

**모의절차(예시)**: `소티자료 입력 → 연료종류별 소모량 산정 → 저장시설 피해손실 반영 → 결과제공`

### [2/3]
**흐름도**: `기초자료(평시 소모실적) 편집 → 소모량 산정 → 손실 반영 → 결과제공`

**기초자료 편집**: 평시(n개년) 기종별 비행소티/소티당 비행시간·연료소모량, 기지별 유류저장시설 현황(유종별 저장탱크·저장량), 기지별 유조차 현황

**작전계획(입력자료)**: 전시 임무별(AI, DCA 등) 평균 비행시간, 항공기 기종별 급유량

### [3/3]
**상세 로직(①수리식)**
```
비행연료소모(t) = Σ_기종[ 소티수(기종,t) × 기종별 소티당 연료소모량(임무유형별) ]
윤활유소모(t)   = 비행연료소모(t) × 기종별 오일소모비율(경험계수)
정비연료소모(t) = 가동장비수(GTG,Heater 등) × 장비별 시간당 연료소모량 × 가동시간
유류손실(t)     = Σ_기지[ 저장시설피해율(§바 등가원모형 준용) × 저장량(기지) ]
```

**모의결과 자료(안)**: 00기지 일자별 비행연료 소모량, 00항공기 특정기간 윤활유 소요량 등 필터링 조회 예시

## 차. 수리부속 소요 산정 (SFR-010) — BORAME 고장확률모형 계승

### [1/3]
**모의기능식별**: 소모보충소요(항공기·기타장비 소모)/피해보충소요(전투손상 복구·기지공격 피해) 구분, 일자별/작전단계별/기지별/기종별 산출

**모의개념**: BORAME가 이미 사용 중인 "ABD시 고장확률·시간당 고장확률·K-Factor" 입력체계를 그대로 계승하여 소요 산정

**모의절차(예시)**: `가동시간 입력 → 고장확률·K-Factor 적용 → 소모/피해 소요 산정`

### [2/3]
**흐름도**: `기초자료(수리부속DB) 편집 → 고장확률 적용 → 소요산정 → 결과제공`

**기초자료 편집**: 수리부속분류·항공기 기종·ABD시 고장확률·시간당 고장확률·K-Factor(BORAME 입력화면 그대로 계승 — 신규 개발 부담 없음)

**작전계획(입력자료)**: 항공기 손실 등급(소파/중파/대파), 기종별 전시 실시임무 및 소티

### [3/3]
**상세 로직(①수리식 / ⑤BORAME 기능개선·통합)**
```
소모보충소요(t) = Σ_부속[ 가동시간(장비,t) × 시간당고장확률(부속) × K-Factor(부속) ]
피해보충소요(t) = Σ_장비[ ABDR전이수(장비,t) × ABD시고장확률(부속|장비피해등급) ]
```
- BORAME 입력화면(분류속성·부속특성·ABD시고장확률·시간당고장확률·K-Factor 그리드)을 **그대로 계승**하며, 전투손실/비전투손실(장비수명) 구분 로직만 목표체계 전용으로 확장

**모의결과 자료(안)**: 수리요청항공기수, 정비활동보고서, 수리부속보고서(BORAME 출력 스키마 계승)

## 카. 물자 소요 산정 (SFR-011) — 완전 신규 개발

### [1/3]
**모의기능식별**: 소모보충소요(병력·장비·부대운용 관련)/피해보충소요(인원·장비·시설 피해 연동), 1~8종 全물자 대상

**모의개념**: 인원(§사)·장비(§마·§바) 소요산정 결과를 연동하여 물자 소모를 파생 계산

**모의절차(예시)**: `편제인원·피해인원 입력 → 물자종별 소모기준 적용 → 소요 산정`

### [2/3]
**흐름도**: `기초자료(인원편제) 편집 → 물자종 매핑 → 소요산정 → 결과제공`

**기초자료 편집**: 아 인원편제(계급별·병과별) 현황, 기지별 인원·장비 현황, 물자종(1~8종)별 기준소모량표

**작전계획(입력자료)**: 작전강도별 소모 가속계수

### [3/3]
**상세 로직(①수리식)**
```
소모보충소요(t) = Σ_물자종(1~8종)[ 편제인원(계급·병과) × 1인당 기준소모량(물자종) × SF_작전강도 ]
피해보충소요(t) = Σ_물자종[ 피해인원(§사) × 물자유형별_손실연동계수 ]
                 + Σ_물자종[ 시설피해율(§바) × 창고보관물자량 ]
```

**모의결과 자료(안)**: 물자종별·기지별 소요표

## 타. 결과 분석 단계 (SFR-012)

### [1/3]
**모의기능식별**: 6대 자산 피해·소모 산출결과 제공, 직접/간접 피해 구분, 필터링, 대시보드, 도움말, PDF 자동생성, 엑셀·CSV 다운로드, 상황도 연계

**모의개념**: §라~카 6대 자산 산출물을 공통 스키마로 통합해 대시보드·보고서로 렌더링

**모의절차(예시)**: `자산별 산출 DB 입력 → 필터링/집계 → 대시보드·보고서 자동생성`

### [2/3]
**흐름도**: `자산별 결과 DB 연동 → 공통 스키마 변환 → 대시보드·상황도 렌더링 → 저장/출력`

**기초자료 편집**: §라~카 각 자산 산출물(자산유형·일자·작전단계·기지·원인 필드 공통화)

**작전계획(입력자료)**: 사용자 대시보드 구성 설정(차트유형·필터조건 저장)

### [3/3]
**상세 로직 (④국방자원관리체계 연동)**
```
{ 자산유형, 일자, 작전단계, 기지, 기종/탄종/물자종, 전투손실, 비전투손실, 누적소요, 보유대비충족률 }
```
- **국방자원관리체계(국방군수통합정보체계) 연동**: 위 스키마의 "보유대비충족률" 필드는 국방자원관리체계의 현재원(現在員) DB를 실시간(또는 배치) 연계해 산정 — 이 지점이 목차상 DAR(데이터요구사항)와 SFR-012(결과분석)를 잇는 **연동 지점**이며, 지금 목차에 빠져 있던 "국방자원관리체계 연동"을 여기서 명시적으로 보여줘야 함
- 직접(적공격)/간접(시설피해) 피해는 §라~카 각 산정식의 "원인코드"(전투손실=직접, 비전투손실 중 시설피해기인=간접)로 자동 분류

**모의결과 자료(안)**: 대시보드 화면(안), 항목별 요약 도움말, PDF 자동생성 보고서, 엑셀/CSV 데이터셋, 상황도 연계 부대별 자산·피해 정보
