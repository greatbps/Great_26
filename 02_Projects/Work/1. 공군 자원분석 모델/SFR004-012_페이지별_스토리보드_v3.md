# Ⅲ-2. 기능요구사항 — 페이지별 스토리보드 v3 (라~타, 총 27P)

**v3 개정사항**: 라(특수전부대·화학탄·드론) 3개 항목에 **위협 시나리오 입력표 + 판정흐름도(if-then)** 신규 추가. 그 외 마~타는 v2와 동일.

**원칙**: 목차의 1)2)3)... 세부항목 = 페이지 1장. 담당업체(아레스/싸이버텍) 태그는 제공하신 목차 그대로 유지. 기능 설명마다 그 기능이 쓰는/만드는 DB 테이블·필드를 같은 페이지 안에서 함께 풀어씀.

## [전체 구조도] STORM 캐스케이드 — 이 챕터 전체를 관통하는 한 장

```
STORM ──┬──▶ 마.항공기 ───┬──▶ 사.인원 (旣산출자료: 마의 항공기피해 재입력)
        ├──▶ 바.작전지원장비 ─┴──▶ 자.유류 (旣산출자료: 마+부대피해 재입력)
        ├──▶ 아.탄약 (STORM 직접 + KAFARAM 준용)                    
        └──▶ 차.수리부속 (STORM 직접 + DELIIS 연동)      사·바 산출물 ──▶ 카.물자 (旣산출자료)
```
- **STORM 직접소비 4개**: 마·바·아·차 / **旣산출자료 재소비 3개**: 사·자·카
- **DELIIS(국방후속군수지원종합정보체계) 연동 2곳**: 바, 차

**본 사업은 전투모의(시뮬레이션)가 아니라 결정형 산정모델이므로, 육군 M&S식 시나리오 스크립트 엔진(`만약/명령/설정`)은 채택하지 않습니다.** 대신 라(특수전부대·화학탄·드론) 항목에 한해 사람이 위협조건을 직접 넣는 **파라미터 입력표**와, 조건분기가 있는 산정로직을 보여주는 **판정흐름도(if-then)**를 아래처럼 반영합니다.

## 라. 모의기능 개발 (SFR-004, 5P, 담당 아레스)
**항목 헤더**: 핵심메시지 "신뢰성 있는 표준알고리즘 기반 신규모의논리" / 평가포인트 "피해율 산정 로직의 과학적 근거" / 우선순위 최상 / 템플릿 수리모델설계형

### 1) 모의기능 개발 범위(특수전부대·화학탄·드론 피해율)
- **Governing Message**: STORM이 모의하지 못하는 3대 위협의 피해율을 신규 산정식으로 개발해 STORM 결과에 보정 반영한다.
- **본문**: 3대 위협 정의, 개발 범위 다이어그램(위협유형→산정식→6대자산 반영)
- **DB 연계**: `TBL_THREAT_SCENARIO`(위협유형코드, 시나리오ID, 기지ID, 일자) — 이후 2)~4) 페이지의 입력 테이블로 공용

### 2) 특수전부대 피해율 모의방안(기지강습/지상침투 구분)
- **Governing Message**: 침투유형별(기지강습/지상침투) 피해를 아 방어전력 저지율과 연동해 산정한다.

**위협 시나리오 입력표**
| 입력항목 | 설명 | 예시 |
|---|---|---|
| 침투조수 | 침투 부대(조) 수 | 3개조 |
| 침투유형 | 기지강습 / 지상침투 | 기지강습 |
| 침투경로(기동로) | 지상침투 시 접근경로 | 기동로A |
| 목표기지 | 공격 대상 기지 | 00기지 |
| 목표당 평균파괴력 | 조당 예상 파괴 규모 | 계수입력 |
| 침투일자·시각 | 공격 발생 시점 | D+3일 |

**판정흐름도(if-then)**
```
시작 → 침투유형 판정
 ├─[기지강습]→ 방공망돌파 성공확률 계산
 │      ├─ 성공 → 목표당파괴력 × (1−아방어전력_저지율) → 피해량 산출
 │      └─ 실패 → 피해량=0, 침투실패 기록
 └─[지상침투]→ 접근성공확률 계산(지형·경계밀도)
        ├─ 성공 → 원거리사격_피해기대값 적용 → 피해량 산출
        └─ 실패 → 피해량=0
→ 종료(라-⑤로 결과 전달)
```
- **수리식**:
  ```
  기지강습피해 = 침투조수 × 성공확률(방공망돌파) × 목표당_평균파괴력 × (1−아방어전력_저지율)
  지상침투피해 = 침투조수 × 접근성공확률(지형·경계밀도) × 원거리사격_피해기대값
  ```
- **DB 연계**: `TBL_SOF_INFIL`(침투조수, 침투유형, 성공확률, 기동로ID, 침투일시) ↔ `TBL_DEFENSE_UNIT`(초소밀도, 기동타격대 대응시간, 경계강도)

### 3) 화학탄 피해율 모의방안(표준확산모델 적용)
- **Governing Message**: 표준 대기확산모델로 오염범위·지속시간을 계산하고, 강화시설 면역 로직을 그대로 반영한다.

**위협 시나리오 입력표**
| 입력항목 | 설명 | 예시 |
|---|---|---|
| 작용제 종류 | 화학작용제 유형 | 신경작용제 |
| 사격량(발수) | 화학탄 사격 발수 | 12발 |
| 표적기지 | 공격 대상 기지 | 00기지 |
| 풍향·풍속 | 확산모델 입력기상 | 북서 5m/s |
| 대기안정도 | 확산모델 입력기상 | 중립 |
| 사격일시 | 공격 발생 시점 | D+5일 06:00 |

**판정흐름도(if-then)**
```
시작 → 표적이 강화시설(엄체·지하)인가?
 ├─ Yes → 피해=0 (BORAME 강화시설 면역 로직 계승) → 종료
 └─ No  → 확산모델 적용(풍향·풍속·대기안정도)
        → 노출시간 계산 → 표적유형별 취약도 적용 → 피해율 산출 → 종료
```
- **수리식**:
  ```
  화학피해율(지점,t) = 확산모델(풍향,풍속,기온,지형) × 표적별_노출시간 × 표적유형별_취약도
  강화시설_화학피해 = 0
  ```
- **DB 연계**: `TBL_CHEM_ATTACK`(작용제종류, 사격량, 표적기지, 기상조건ID, 사격일시) + `TBL_WEATHER`(풍향, 풍속, 대기안정도)

### 4) 드론 피해율 모의방안(공격형태별 구분)
- **Governing Message**: JWS 무장효과DB의 격자보간 방식을 드론에 그대로 확장 적용해 신규 무장DB 구축 없이 피해율을 산출한다.

**위협 시나리오 입력표**
| 입력항목 | 설명 | 예시 |
|---|---|---|
| 드론유형 | 자폭형/정찰형/공격형 등 | 자폭형 |
| 탄두중량 | JWS 등가환산 기준값 | 5kg |
| 속도·고도 | 요격확률 산정 입력 | 120km/h, 500m |
| 공격형태 | 급강하/저고도침투 등 | 저고도침투 |
| 표적기지 | 공격 대상 기지 | 00기지 |

**판정흐름도(if-then)**
```
시작 → 대드론요격체계 탐지·요격 판정
 ├─ 요격성공 → 피해=0, 요격기록 저장 → 종료
 └─ 요격실패 → 탄두중량 JWS 등가환산
        → JWS격자(무장코드×각도×거리) 선형보간 피해율 산출
        → 공격형태별 구분 반영 → 종료
```
- **수리식**: `드론피해율 = Σ_드론유형[ 침투성공확률(대드론요격률) × JWS보간_피해율(탄두중량 등가환산) ]`
- **DB 연계**: `TBL_DRONE_SPEC`(드론유형, 탄두중량, 속도, 고도, 공격형태) → `TBL_JWS_GRID`(무장코드, 각도, 거리, 피해율) 등가매핑 뷰(`VW_DRONE_JWS_MAP`)

### 5) 모의결과의 6대 자산 반영방안(원인별·일자별 구분)
- **Governing Message**: 2)~4)의 피해율을 6대 자산 소요산정 모듈의 공통 입력으로 원인코드 태깅해 전달한다.
- **본문**: 원인코드 체계(특수전/화학/드론/기타), 일자별 누적 반영 흐름
- **DB 연계**: `TBL_THREAT_RESULT`(원인코드, 일자, 기지ID, 피해량) — 마~카 전 항목이 공통으로 참조하는 연동 허브 테이블

## 마. 장비(항공기) 소요 산정 (SFR-005, 2P, 담당 아레스) — ◆STORM 직접소비

### 1) 전투/비전투 손실 구분 산정
- **Governing Message**: 적공격에 의한 전투손실과 사고에 의한 비전투손실을 분리 산정한다.
- **본문(수리식)**:
  ```
  전투손실(t) = Σᵢ 출격소티(i,t) × 피격확률(i,t) × Kill전이확률(무장유형,교전거리,각도)
  비전투손실(t) = 가동소티(t) × 기종별_사고율(연간사고율/365) × SF_기상
  ```
- **DB 연계**: `TBL_AC_LOSS`(기종ID, 손실유형, 일자, 원인코드) — `TBL_THREAT_RESULT`(라-⑤)와 원인코드로 조인

### 2) 항공기 소요산정 절차(STORM 입력→소요 산출)
- **Governing Message**: STORM 출력값을 표준 스키마로 정규화해 敵공격 형태별(공대공/지대공/특수전) 손실을 구분 산출하고, STORM 非모의 기종은 별도 입력경로로 보완한다.
- **본문**:
  - **STORM 직접 출력값(원문)**: `항공기 손실` · `기종별 전시 임무 및 소티` · `전구급 我 부대 피해(항공침투, TBM 등) 현황`
  - **STORM 갭 보완**: STORM 非모의 기종(KC-330 공중기동기, RC-800 감시통제기 등)은 STORM 출력에 없으므로 "전시 계획 임무 및 소티"를 체계에 별도 입력하는 화면 제공
  - **격추비 파라미터화**: 항공공격:지대공공격 = 7:3, 항공공격(공대공):기총 = 9:1 등 敵아 격추비율을 사용자 조정 가능한 계수로 설계(고정값 아님)
  - 산출: 일자별/작전단계별/기종별/기지별 ①전투손실량(율) ②비전투손실량(율) ③총소요량(율)
- **DB 연계**: `TBL_STORM_IMPORT`(원본파일ID, 기종ID, 손실량, 소티수, 임포트일시) + `TBL_STORM_MAPPING`(필드유형, STORM필드명, 목표체계필드명) + `TBL_KILL_RATIO`(공격유형A, 공격유형B, 비율) + `TBL_NONSTORM_AC_PLAN`(기종ID, 계획임무, 소티, STORM비모의여부)

## 바. 장비(작전지원장비) 소요 산정 (SFR-006, 2P, 담당 아레스) — ◆STORM 직접소비 + ◆DELIIS 연동

### 1) 전투/비전투 손실 구분 산정
- **Governing Message**: 노천 배치장비는 등가원 피해모형, 엄체 배치장비는 BORAME 면역로직으로 구분 산정한다.
- **본문(수리식)**:
  ```
  전투손실(t) = Σ_기지[ 노천배치장비(기지) × 등가원피해율(기지,t) ]
              + Σ_기지[ 엄체보관장비(기지) × 강화시설면역계수(=0) ]
  비전투손실(t) = 보유량 × (1/내용년수) × (Δt/365) + 결함율(장비유형)
  ```
- **DB 연계**: `TBL_EQUIP_DEPLOY`(장비ID, 배치유형[노천/엄체], 기지ID, 배치면적)

### 2) 작전지원장비 소요산정 절차
- **Governing Message**: STORM 부대피해 현황을 BORAME 시설피해 방법론으로 계산하고, 敵 공격별(항공기/TBM) 구분과 DELIIS 연동으로 BORAME의 두 가지 미흡점을 보완한다.
- **본문**:
  - **STORM 직접 출력값(원문)**: `전구급 我 부대 피해(항공침투, TBM 등) 현황`
  - **BORAME 계승**: 등가원 피해모형(R=√LW/π), 강화시설 면역 로직 그대로 재사용
  - **BORAME 미흡점 보완①**: 敵 공격별(항공기/TBM) 구분 손실 산출 기능 신규 추가 — TBM은 탄착오차(CEP)를 고려해 주요시설 외 탄착 피해도 별도 반영
  - **BORAME 미흡점 보완②(DELIIS 연동)**: "작전지원장비 종별 수량 및 최대·최소 수명"은 DELIIS 데이터 자료 업로드로 자동 연계
  - 산출: 일자별/작전단계별/**기능별**/기종별/기지별 ①전투손실량(율) ②비전투소모량(율) ③총소요량(율)
- **DB 연계**: `TBL_EQUIP_SPEC`(장비유형, 내용년수, 결함율) + `TBL_FACILITY_SHAPE`(기지ID, 배치구역ID, 길이L, 너비W) → `VW_EQUIV_RADIUS` + `TBL_ATTACK_TYPE_DMG`(공격유형[항공/TBM], CEP, 탄착위치) + `TBL_DELIIS_SYNC`(자료유형='장비수명', 동기화일시, 상태)

## 사. 인원 소요 산정 (SFR-007, 2P, 담당 아레스) — ◆旣산출자료 재소비 (STORM 아님)

### 1) 전투/비전투 손실 구분 산정
- **Governing Message**: BORAME에 없는 인명피해 모형을 신규 개발해, 마(항공기)의 산출 결과를 재입력받아 시설피해율에 인원배치밀도를 연동한 기대손실모형으로 산정한다.
- **본문(수리식)**:
  ```
  전투손실인원(t) = Σ_기지[ 시설피해율(기지,t) × 배치인원(기지,병과) × 인명노출계수(K_exp) ]
                  + 특수전부대_교전손실인원(라-② 인계) + TBM_피해인원(고폭탄/화학탄 구분)
  비전투손실인원(t) = 편제인원 × 일일기저손실률(질병·사고) × (1+전시스트레스계수×작전강도)
  ```
- **본문(旣산출자료 명시)**: 입력원 = `임무 수행 간 항공기 피해`(마의 산출물, STORM 아님) + `我 부대 피해(항공침투, TBM 등) 현황`(특수전부대 피해 포함) — **BORAME 완전 공백 영역, 100% 신규개발**
- **DB 연계**: `TBL_PERSONNEL_ORG`(기지ID, 계급, 병과, 편제인원수) + `TBL_EXPOSURE_FACTOR`(근무형태, 방호시설여부, K_exp값) + `TBL_AC_LOSS`(마의 산출물, FK 참조)

### 2) 인원소요산정 절차(신분·계급·특기별)
- **Governing Message**: 공중임무/항공공격/TBM/특수전/기타부대(TACP·CCT·항공구조사)·비전투 6개 원인별로 세분화해 신분·계급·특기별로 집계한다.
- **본문**: 6개 손실 원인(①공중임무손실 ②항공공격손실 ③TBM손실[고폭탄/화학탄 구분] ④특수전공격손실 ⑤기타부대인원손실 ⑥비전투손실) 분류체계, 집계 흐름도

## 아. 탄약 소요 산정 (SFR-008, 2P, 담당 아레스) — ◆STORM 직접소비 + ◆KAFARAM 준용

### 1) 탄종별 구분 산정(KAFARAM 준용)
- **Governing Message**: STORM의 항공기 손실·격추수(율)를 KAFARAM의 탄종별 소모량(율) 판단 로직에 대입해 검증된 값으로 산정한다.
- **본문**:
  - **STORM 직접 출력값(원문)**: `항공기 손실` · `기종별 실시 임무 비율 및 소티` · `항공기 및 무기별 敵 항공기 격추수(율)` · `항공기 기종별 손실률`
  - **KAFARAM 준용**: 敵아 격추비(항공기:지대공=7:3, 공대공:기총=9:1 등)를 반영한 KAFARAM 소모율 로직을 그대로 재사용하여 공대공/공대지/일반폭탄/특수목적탄/방공유도탄/기타탄약 산정
  ```
  탄종별소모량(t) = Σ_기종[ 소티수(기종,t) × 무장탑재량(기종,탄종) × 명중률가정 ]
                   + 대공방어_소모량(지대공유도탄, 요격시도횟수 × 발사기준)
  ```
- **BORAME 미흡점 대비**: KAFARAM은 "소모량(율) 판단"까지만 제공 — 확보·비축 목표 계층은 목표체계에서 신규 추가(2)번 참조)
- **DB 연계**: `TBL_KAFARAM_IMPORT`(탄종코드, 소모율, 기종ID, 임포트일시) + `TBL_AMMO_STOCK`(탄종코드, 기보유량, 안전재고계수)

### 2) 탄약소요산정 절차
- **Governing Message**: 전시 365일 기준 일자·단계별 누적소모 곡선을 산출하고, 前연구 대비 비교결과표와 3군 공통탄약을 KAFARAM에는 없던 신규 계층으로 추가한다.
- **본문(수리식)**: `탄종별기간소요(t~t+Δ) = Σ탄종별소모량 − 기보유량 + 안전재고계수×예상소모율`
- **본문(신규 계층)**: ①탄종별 소모량(율) ②탄종별 기간별 소요(확보·비축목표) **前연구 대비 비교결과표** ③탄종별 단계별 일일 소요계수(지상탄약 포함) ④**3군 공통탄약 소요량**
- **DB 연계**: `TBL_AMMO_REQUIREMENT`(일자, 단계, 탄종코드, 소요량, 육군공통여부) + `TBL_PRIOR_STUDY_COMPARE`(탄종코드, 前연구값, 신규값, 차이율)

## 자. 유류 소요 산정 (SFR-009, 2P, 담당 아레스) — ◆旣산출자료 재소비 (STORM 아님, BORAME·KAFARAM 완전 공백)

### 1) 비행연료·윤활유·정비연료·손실 구분 산정
- **Governing Message**: BORAME·KAFARAM 어디에도 없는 유류 모델을 완전 신규 개발한다. 소티 기반 소모량과 저장시설 피해손실을 구분 산정한다.
- **본문(수리식)**:
  ```
  비행연료소모(t) = Σ_기종[ 소티수(기종,t) × 기종별 소티당 연료소모량(임무유형별) ]
  윤활유소모(t) = 비행연료소모(t) × 기종별 오일소모비율
  정비연료소모(t) = 가동장비수(GTG,Heater 등) × 장비별 시간당 연료소모량 × 가동시간
  유류손실(t) = Σ_기지[ 저장시설피해율(바-② 등가원모형 준용) × 저장량(기지) ]
  ```
- **본문(旣산출자료 명시)**: 입력원 = `我 全기종 전시 임무 및 소티` + `임무 수행 간 항공기 피해`(마의 산출물) + `我 부대 피해 현황`(특수전부대 피해 포함) — STORM 직접 아님
- **DB 연계**: `TBL_FUEL_CONSUME_RATE`(기종ID, 임무유형, 소티당소모량) + `TBL_FUEL_STORAGE`(기지ID, 유종, 저장탱크용량, 현재저장량) + `TBL_AC_LOSS`(마 산출물 FK)

### 2) 유류소요산정 절차
- **Governing Message**: 평시(n개년) 실적 데이터를 기반으로 전시 소모 패턴을 환산해 일자·기지·기종·원인별로 산출한다.
- **본문**: 평시 실적(기종별 비행소티·소티당 비행시간·연료소모량, 정비연료·윤활유 소모량) → 전시 임무별(AI, DCA 등) 환산 흐름도. 원인: 유류저장시설 파손/항공기 파손/유조차 파손 구분
- **DB 연계**: `TBL_FUEL_HISTORY`(연도, 기종ID, 소티수, 소모량)

## 차. 수리부속 소요 산정 (SFR-010, 2P, 담당 아레스) — ◆STORM 직접소비 + ◆DELIIS 연동 (BORAME 2대 강점 영역)

### 1) 소모보충·피해보충 구분 산정
- **Governing Message**: BORAME의 고장확률·K-Factor 입력체계를 그대로 계승하되, 항공기 외 장비까지 확장하고 손실/손상 교환비를 신규 반영한다.
- **본문(수리식)**:
  ```
  소모보충소요(t) = Σ_부속[ 가동시간(장비,t) × 시간당고장확률(부속) × K-Factor(부속) ]
  피해보충소요(t) = Σ_장비[ ABDR전이수(장비,t) × ABD시고장확률(부속|장비피해등급) ]
  ```
- **BORAME 계승**: `TBL_PART_FAILURE`(부속코드, ABD시고장확률, 시간당고장확률, K_Factor) — BORAME 입력화면 스키마 그대로
- **BORAME 미흡점 보완①(장비 확장)**: 항공기 부속 중심이던 BORAME 범위를 항공기 외 장비(방공유도무기, 지원장비)로 확장
- **BORAME 미흡점 보완②(교환비 신규)**: 장비별 손실/손상 교환비(예: 손실 1 : 손상 1.4) 파라미터 신규 반영
- **DB 연계**: `TBL_PART_FAILURE` + `TBL_LOSS_DAMAGE_RATIO`(장비유형, 손실비, 손상비)

### 2) 수리부속소요산정 절차
- **Governing Message**: STORM의 항공기 손상등급(소파/중파/대파)과 DELIIS 저장수량·소모실적을 연동해 요인별로 소요를 산정한다.
- **본문**:
  - **STORM 직접 출력값(원문)**: `항공기 손실(소파/중파/대파)` · `기종별 전시 실시 임무 및 소티` · `전구급 我 부대 피해 현황`
  - **STORM 갭 보완**: STORM 非모의 기종(KC-330, KT-1 훈련기, RC-800 등)은 별도 계획 임무·소티 입력
  - **DELIIS 연동(BORAME 미흡점 보완③)**: "수리부속별 기지별 창고 저장 수량", "평시 장비별 연간 수리부속 소모실적"은 DELIIS 데이터 자료 업로드로 자동 연계(장비대상: 항공기·방공유도무기·지원장비)
  - 요인별 산출: 전시 항공기 운용소요 / 항공기 외 장비 운영소요 / 전투손상 복구소요 / 창고 피해에 의한 피해량(율)
- **DB 연계**: `TBL_AC_DAMAGE_GRADE`(기종ID, 일자, 손실등급) + `TBL_DELIIS_SYNC`(자료유형='수리부속재고'/'소모실적') → `VW_PART_REQUIREMENT`

## 카. 물자 소요 산정 (SFR-011, 2P, 담당 아레스) — ◆旣산출자료 재소비 (STORM 아님, BORAME·KAFARAM 완전 공백)

### 1) 소모보충·피해보충 구분 산정(1~8종 물자)
- **Governing Message**: BORAME·KAFARAM 어디에도 없는 물자 모델을, RFP가 직접 제시한 산정논리 예시를 그대로 구현해 완전 신규 개발한다.
- **본문(RFP 원문 산정논리 그대로 반영)**:
  ```
  [1종 식량류 - 전투식량]
  소요량 = (비축소요인가기준 ÷ 6일 × 전시단계별 운영일수) + (창고별 저장량 × 창고피해율)

  [2종 피복 - 개인피복]
  소요량 = Σ(편제인원 × 재보급기준 ÷ 365일) + Σ(일별 인원피해 × 피해기준) + (창고별 저장량 × 창고피해율)

  ※ 2종 중 특수피복은 "병과피복"과 "환자피복"의 산정논리를 별도 구분
    - 병과피복: 편제인원 재보급주기에 연동
    - 환자피복: 일별 인원피해 발생량에 연동
  ```
- **본문(旣산출자료 명시)**: 입력원 = `我 인원편제(계급별·병과별) 현황`(사의 산출물) + `我 기지별 인원·장비·시설 피해 현황`(항공/TBM/특수전부대 피해 전부 포함, 사·바 산출물 통합) — **6대 자산 중 유일하게 2개 자산(인원+장비)의 산출물을 동시에 물려받는 최하류 모듈**
- **DB 연계**: `TBL_SUPPLY_CLASSIFY`(대구분1~8종, 중구분, 소구분, 대상품목, 산정논리코드) + `TBL_PERSONNEL_LOSS`(사 산출물 FK) + `TBL_EQUIP_DEPLOY`/`TBL_FACILITY_SHAPE`(바 산출물 FK)

### 2) 물자소요산정 절차(품목 그룹화 산정논리)
- **Governing Message**: 품목(품목번호·FSC·NIIN) 단위를 물자종 단위로 그룹화해 산정 부하를 줄이고, 물자 특성(약품·화생방물자·피복 등)을 고려한 소요량을 자동 선택된 산정논리로 계산한다.
- **본문**: 품목→물자종 그룹화 매핑 흐름도, 대구분(1~8종)-중구분-소구분-대상품목 4단계 분류체계
- **DB 연계**: `TBL_ITEM_GROUP_MAP`(품목코드[품목번호/FSC/NIIN], 물자종코드)

- **본문**: 항목ID→산정로직 설명문 매핑
- **DB 연계**: `TBL_HELP_TEXT`(항목코드, 설명문, 관련산정식ID)

### 6) 분석결과·대시보드 PDF 자동 생성
- **Governing Message**: 현재 조회 중인 대시보드 상태를 정형 PDF 문서로 즉시 출력한다.
- **본문**: 대시보드 스냅샷 → PDF 템플릿 렌더링 흐름
- **DB 연계**: `TBL_REPORT_LOG`(생성일시, 사용자ID, 대시보드ID, 파일경로)

### 7) 데이터셋 엑셀·CSV 다운로드 기능
- **Governing Message**: 원본 데이터셋을 엑셀·CSV로 내보내 후속 분석·보고서 작성을 지원한다.
- **본문**: 다운로드 범위 선택(필터 적용 결과 기준) → 파일 생성
- **DB 연계**: `VW_ASSET_RESULT_ALL` 뷰를 그대로 내보내기 소스로 재사용

### 8) 상황도 연계 부대별 자산·피해 정보 표시
- **Governing Message**: 지도 기반 상황도 위에 부대별 자산 현황·피해 정보를 오버레이 표시한다.
- **본문**: 기지ID/부대ID → 좌표 매핑 → 상황도 마커 렌더링
- **DB 연계**: `TBL_BASE_LOCATION`(기지ID, 위경도) + `TBL_RESULT_UNIFIED` 조인 뷰(`VW_MAP_OVERLAY`)
