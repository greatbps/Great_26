# 🏨 1️⃣ 호텔 객실정보 관리 시스템 = PMS 핵심 정의

👉 PMS(Property Management System)는

> **“객실 + 고객 + 예약 + 요금 + 운영”을 통합 관리하는 호텔의 코어 시스템**

쉽게 말하면  
👉 ERP + CRM + 예약 시스템 + 운영 시스템 합쳐진 것

---

# 🧩 2️⃣ 전체 구조 (현실적인 아키텍처)

현업 기준 구조는 이렇게 본다👇

[외부 채널]  
 OTA / Booking / Agoda / 자사 웹  
  
        ↓  
  
[예약/채널 관리]  
 CRS / Channel Manager  
  
        ↓  
  
[핵심 PMS]  
 ├ 예약 관리  
 ├ 객실 관리  
 ├ 요금/Revenue  
 ├ 고객 프로파일  
 ├ 프론트 운영  
  
        ↓  
  
[연계 시스템]  
 POS / 결제 / CRM / ERP / IoT / BMS  
  
        ↓  
  
[인프라]  
 On-Prem / Cloud / Hybrid

---

# 🧠 3️⃣ 핵심 요구사항 (RFI 대응용 핵심)

이건 그냥 기능 나열하면 안 되고  
**“왜 필요한지”까지 같이 써야 먹힌다**

---

## 🎯 1. 예약/객실 관리 (Core)

- 실시간 객실 상태 (Available / Occupied / Dirty / OOO)
- 오버부킹 관리
- 다중 채널 예약 통합 (OTA, 웹, 콜센터)

👉 핵심:  
**“실시간 동기화 + 충돌 방지”**

---

## 🎯 2. 고객 프로파일 (🔥 중요)

- 고객 히스토리 (투숙, 소비, 선호도)
- VIP / 등급 관리
- 마케팅 연계

👉 핵심:  
**“단순 숙박이 아니라 고객 데이터 플랫폼”**

---

## 🎯 3. 요금 및 수익관리 (Revenue Management)

- 동적 요금 (Dynamic Pricing)
- 시즌/이벤트 요금
- 채널별 가격 차등

👉 핵심:  
**“매출 최적화 엔진”**

---

## 🎯 4. 프론트 오퍼레이션

- 체크인 / 체크아웃
- 키 발급 (모바일 키 포함)
- 룸 업그레이드

👉 핵심:  
**“고객 경험 속도 + 자동화”**

---

## 🎯 5. 하우스키핑 / 유지관리

- 객실 청소 상태 관리
- 유지보수 요청 (Engineering)
- 모바일 앱 기반 업무 처리

👉 핵심:  
**“현장 운영 디지털화”**

---

## 🎯 6. 결제 및 정산

- 다양한 결제 수단 (카드, 간편결제)
- Folio 관리
- 세금/정산 처리

👉 핵심:  
**“정확성 + 통합 회계 연계”**

---

## 🎯 7. 통합 및 연계 (🔥🔥 핵심)

- POS (레스토랑, 카지노)
- CRM / 마케팅
- ERP / 재무
- BMS / IoT (객실 자동화)

👉 핵심:  
**“PMS는 허브 시스템”**

---

# 🧱 4️⃣ 기능 구성도 (RFI용 바로 사용 가능)

[PMS Core]  
  
1. Reservation Management  
   - 예약 생성/변경/취소  
   - 채널 통합  
   - No-show 관리  
  
2. Room Management  
   - 객실 상태  
   - 룸 할당  
   - 업그레이드  
  
3. Guest Management  
   - 고객 프로파일  
   - VIP 관리  
   - 히스토리  
  
4. Front Desk Operations  
   - 체크인/아웃  
   - 키 관리  
   - 요청 처리  
  
5. Housekeeping  
   - 청소 상태  
   - 작업 할당  
   - 모바일 처리  
  
6. Billing & Payment  
   - Folio  
   - 결제 처리  
   - 정산  
  
7. Revenue Management  
   - 요금 정책  
   - 프로모션  
   - 수익 분석  
  
8. Reporting & Analytics  
   - 점유율  
   - 매출  
   - KPI  
  
9. Integration Layer (API)  
   - OTA / POS / CRM / ERP / IoT

# ⚙️ 5️⃣ 아키텍처 요구사항 (진짜 중요)

이건 대부분 업체들이 약하게 쓰는 부분인데  
👉 여기서 차별화 가능

---

## 🔥 1. 실시간 처리

- 예약/객실 상태 실시간 반영
- OTA 연동 지연 최소화

👉 이벤트 기반 아키텍처 추천 (Kafka 등)

---

## 🔥 2. 고가용성 (카지노 때문에 필수)

- 24/7 무중단
- Active-Active 구조
- DR/BCP 필수

👉 이거 쓰면 바로 신뢰 올라간다

---

## 🔥 3. API First 구조

- 모든 기능 API 제공
- 외부 시스템 쉽게 붙게

👉 “플랫폼화”

---

## 🔥 4. 클라우드/하이브리드

- PMS는 SaaS or Private Cloud
- 핵심 데이터는 온프레 유지 가능

---

## 🔥 5. 보안

- 개인정보 (PII)
- 결제 정보 (PCI-DSS)
- 접근제어 (RBAC)

---

# 🧠 6️⃣ 요즘 트렌드 (한 줄씩만 박아도 효과 있음)

👉 RFI에 넣으면 좋은 키워드

- Mobile Check-in / Keyless Entry
- AI 기반 수요 예측
- 고객 맞춤 서비스 추천
- IoT 기반 스마트 객실
- Data Lake 기반 고객 분석

---

# 💣 7️⃣ 이걸 RFI에서 어떻게 써먹냐

핵심 문장 하나 준다👇

> “PMS를 단순 운영 시스템이 아닌,  
> 고객 경험과 수익 최적화를 동시에 구현하는  
> 통합 디지털 플랫폼으로 설계”

👉 이 문장 하나면  
**레벨이 달라 보인다**

---

# 🔥 결론 (진짜 중요한 포인트)

👉 PMS는 “기능 시스템”이 아니다

> **호텔 전체를 연결하는 ‘허브 플랫폼’이다**
