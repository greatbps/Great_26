# 1️⃣ 한 줄 핵심 정리

👉 이건 **“호텔 하나 설계 + 그룹 전체 인프라 리빌딩”**  
👉 그리고 진짜 목적은 **“컨설팅 → RFP → SI → PMO” 풀 체인 확보**

**RFI = 진입 티켓 / RFP = 본게임 / SI = 돈**
