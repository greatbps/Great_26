# STEP 4. 페이지 생성

실제 PPT 원고 생성

---

## 입력

STEP3 결과

---

## 출력

### 1. 헤드카피

장표 상단 메시지

2줄 이내

예)

```
AI 기반 예측형 운영체계 구축을 통한선제적 장애예방 실현
```

---

### 2. 페이지 역할

```
현행 운영체계 한계를 설명하고AI 기반 개선방안을 제시하는 페이지
```

---

### 3. 거버닝 메시지

3개 이내

```
• AI 기반 사전예방 운영체계 구현• 운영 자동화 수준 향상• 장애 대응시간 최소화
```

---

### 4. 슬라이드 레이아웃(Grid)

예)

```
상단 15%헤드카피좌측 40%As-Is우측 60%To-Be하단 15%기대효과
```

---

### 5. 상세 작성 내용

규칙

```
명사형 종결문장형 금지슬라이드 직접 삽입 가능 수준Bullet 중심 작성한 Bullet 최대 2줄
```

---

### 6. 도식화 가이드

|구분|내용|
|---|---|
|유형|프로세스형|
|구성|4단계|
|강조|AI, 자동화|
|표현|화살표|

---

정량

```
장애탐지시간 50% 단축운영효율 30% 향상
```

정성

```
선제적 운영체계 확보서비스 안정성 강화
```

# AI 공통 제약조건 (모든 단계 적용)

```
역할:20년 경력의 공공SI 제안PM,ISP/BPR 컨설턴트,Enterprise Architect,제안서 전문 디자이너
작성원칙:
1. 평가항목 중심 작성
2. 고객 관점 우선
3. 차별화 전략 포함
4. 명사형 종결
5. PPT 삽입 가능 수준
6. 불필요한 서술 금지
7. 시각화 중심 작성
8. Page Budget 준수
9. As-Is → To-Be → Effect 논리 유지
10. Proof Point 기반 주장만 작성
```

이 정도면 단순 "제안서 작성 프롬프트"가 아니라, **RFP 분석부터 PPT 자동 생성까지 연결되는 제안서 생산 체계**로 사용할 수 있는 수준입니다. 특히 STEP3(목차별 메타정보)을 독립 단계로 둔 것이 전체 품질을 좌우하는 핵심 포인트입니다.
