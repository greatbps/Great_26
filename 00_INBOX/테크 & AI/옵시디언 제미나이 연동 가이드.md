## 📝 Summary

## 📄 Content
📌 옵시디언에서 Gemini, NotebookLM 등을 바로 사용할 수 있게 해주는 '이지게이트' 플러그인은 무엇인가요?

'이지게이트'는 옵시디언 내에서 ==웹 브라우저처럼 AI 웹 서비스(Gemini, NotebookLM, Claude 등)를 직접 활용==하여 텍스트 분석, 노트 자동 생성, 마크다운 변환 등을 가능하게 하는 플러그인입니다.

💡 이지게이트 플러그인 설치 방법은?

옵시디언 커뮤니티 플러그인인 ==BRAT을 먼저 설치한 후==, BRAT의 'Add Beta Plugin' 기능을 통해 이지게이트 플러그인 링크를 추가하여 설치할 수 있습니다.

옵시디언에서 Gemini, NotebookLM 등 AI 도구를 바로 활용할 수 있는 **이지게이트 플러그인**을 소개합니다. 이 플러그인을 사용하면 웹 브라우저를 열지 않고도 옵시디언 안에서 AI 분석, 텍스트 변환, 노트 생성을 **원활하게 자동화**할 수 있습니다. AI 기반의 설문지 및 퀴즈 자동 생성 도구인 티보드 폼즈와 연동하여 더욱 강력한 워크플로우를 구축하는 방법을 배우고 싶다면 꼭 확인해보세요.

1. 이지게이트 플러그인 소개 및 기능

옵시디언에서 Gemini, NotebookLM 등 AI 도구를 웹 브라우저 없이 바로 활용할 수 있게 해주는 **이지게이트 플러그인**을 소개하고, 이를 활용한 설문지 및 퀴즈 자동 생성 방법을 안내합니다.

1.1. 이지게이트 플러그인의 특징

1. **기존 오픈 게이트 개선**: 기존 오픈 게이트 플러그인의 불편함을 개선하여 더 쉽게 사용할 수 있도록 만들었습니다.
    
2. **웹 브라우저 기능 내장**: 옵시디언 창 안에서 웹 브라우저처럼 특정 웹사이트(예: 레딧)에 바로 접속하고 이용할 수 있습니다.
    
    - 새로운 창에서 원하는 웹사이트를 열고, X 버튼으로 닫을 수 있습니다.
        
3. **콘텐츠 삽입 기능**: 웹에서 가져온 내용을 현재 커서 위치, 노트의 가장 아래, 또는 새 노트로 바로 삽입할 수 있습니다.
    
4. **API 연동 및 템플릿 활용**: Gemini, Claude, OpenAI, GLM 등의 API를 설정하여 AI를 통한 콘텐츠 개선 및 노트 자동화 작업을 지원합니다.
    

1.2. 이지게이트 플러그인 활용 예시: Gemini를 이용한 블로그 포스트 생성

1. **Gemini 창 열기 및 프롬프트 입력**: 이지게이트 플러그인을 통해 Gemini 창을 열고, 옵시디언 초보자를 위한 추천 플러그인 10개 리스트와 설명을 요청하는 블로그 포스트 작성을 지시합니다.
    
2. **결과 확인 및 노트로 저장**: Gemini가 생성한 플러그인 리스트를 확인하고, 원하는 부분을 드래그하여 '새 노트'로 변환합니다.
    
3. **Q&A 형식으로 변환 및 시각 자료 활용**: 드래그한 텍스트를 Q&A 형식으로 변환하고, 시각 자료를 활용하여 쉽게 볼 수 있도록 요청합니다.
    
    - AI 분석 시작 후, 결과가 표 형식으로 나오면 새 노트로 저장합니다.
        
    - 결과를 차트처럼 한눈에 볼 수 있는 뷰로 제공합니다.
        
4. **기본 프로퍼티스 자동 생성**: 노트 생성 시 출처(Gemini 분석)와 같은 기본 프로퍼티스가 자동으로 포함되며, 제목은 쉽게 수정 가능합니다.
    
    - 이를 통해 별도의 프롬프트 입력 없이 텍스트를 변환하여 옵시디언 노트에 바로 넣을 수 있습니다.
        

1.3. 이지게이트 플러그인 활용 예시: NotebookLM을 이용한 여행지 추천 노트 생성

1. **NotebookLM 창 열기 및 프롬프트 입력**: 이지게이트 플러그인을 통해 NotebookLM 창을 열고, 4인 가족의 500만 원 예산으로 5일간 떠날 수 있는 해외 여행지 추천을 요청합니다.
    
2. **결과 확인 및 블로그 포스트 형식 요청**: NotebookLM의 리서치 결과를 확인하고, 채팅 기능으로 블로그 포스트 형식으로 작성을 요청합니다.
    
3. **선택적 내용 삽입 또는 전체 편집**:
    
    - 원하는 부분만 드래그하여 'Apply' 방식으로 삽입할 수 있습니다.
        
    - 전체 글을 AI로 편집하고 싶을 때는 '분석 열기' 기능을 사용합니다.
        
4. **AI 편집 및 노트 생성**:
    
    - '분석 열기' 후 기본 요약 템플릿을 선택하거나, 텍스트를 붙여넣고 표 형식으로 나타내도록 요청합니다.
        
    - 분석 시작 후 결과가 나오면 '새 노트 작성'을 눌러 페이지를 생성합니다.
        
    - 생성된 노트에는 URL과 제목이 포함되며, 제목은 쉽게 편집 가능합니다.
        
5. **옵시디언 내 노트 생성의 장점**: 다른 사이트를 열지 않고 옵시디언 안에서 무궁무진한 노트 생성이 가능합니다.
    

6. 티보드 폼즈를 활용한 설문지 및 퀴즈 자동 생성

AI를 활용하여 구글 폼을 자동으로 생성해주는 **티보드 폼즈** 프로그램을 소개하고, 이를 이지게이트 플러그인과 연동하여 옵시디언 노트로 만드는 방법을 안내합니다.

2.1. 티보드 폼즈 소개 및 접속 방법

1. **티보드 폼즈란?**: AI를 활용하여 구글 폼을 자동으로 생성해주는 프로그램입니다.
    
2. **접속 방법**: 웹 브라우저 주소창에 `forms.teaboard.link`를 입력하여 접속합니다.
    
3. **구글 로그인**: 구글 계정으로 로그인한 후, 계속 진행하여 화면에 진입합니다.
    

2.2. 티보드 폼즈를 이용한 설문지 생성

1. **퀴즈/설문 생성 선택**: '퀴즈 설문 생성하기'를 클릭합니다.
    
2. **Gemini API 설정**: Gemini API 키 값을 입력해야 하며, 최근 변경된 무료 정책에 따라 결제 티어 1 계정으로 설정하면 비용 부담 없이 사용할 수 있습니다.
    
    - API 키 설정 방법은 유튜브 설명란 링크를 참고합니다.
        
3. **폼 유형 및 내용 입력**:
    
    - 폼 유형을 '설문'으로 선택합니다.
        
    - '여행지 추천 지역 설문'과 같은 제목을 입력합니다.
        
    - 설문 목적, 응답자(예: 30-40대 자녀 동반 부모), 참고 텍스트를 입력합니다.
        
    - 개인 정보 수집 항목으로 '이름과 전화번호'만 받도록 설정합니다.
        
4. **폼 생성 및 확인**: '폼 만들기'를 클릭하면 구글 드라이브에 폼이 저장됩니다.
    
    - **반드시 '편집 화면 열기'를 클릭하여 제대로 작성되었는지 확인해야 합니다.**
        
    - 생성된 폼은 팝업 창으로 열리며, 구글 폼에서 내용을 확인할 수 있습니다.
        
5. **옵시디언으로 임베드**:
    
    - 구글 폼에서 '인베드 HTML' 코드를 복사합니다.
        
    - 옵시디언으로 돌아와 해당 코드를 붙여넣으면 설문 내용이 삽입됩니다.
        
    - 'Share Note' 기능을 통해 설문 제출이 가능해집니다.
        

6. 이지게이트 플러그인 설치 방법

이지게이트 플러그인을 설치하기 위해 **BRAT**라는 커뮤니티 플러그인을 먼저 설치하는 과정을 안내합니다.

3.1. BRAT 플러그인 설치

1. **설정 메뉴 이동**: 옵시디언 하단의 '설정'을 클릭합니다.
    
2. **커뮤니티 플러그인 선택**: '커뮤니티 플러그인'을 선택합니다.
    
3. **BRAT 검색 및 설치**: 'Browse'에서 'Brat'를 검색하여 설치하고 'Enable'을 클릭합니다.
    

3.2. 이지게이트 플러그인 추가 및 설정

1. **BRAT 실행**: 설치된 BRAT 플러그인을 클릭합니다.
    
2. **베타 플러그인 추가**: 'Add beta plugin'을 누릅니다.
    
3. **플러그인 링크 입력**: 공유받은 이지게이트 플러그인 링크를 붙여넣고 'Add plugin'을 클릭하여 설치합니다.
    
4. **웹 게이트 생성**:
    
    - 'Easy Gate'라는 이름으로 새 게이트를 생성합니다.
        
    - URL에 `https://gemini.google.com` 등을 입력하고, 이름에 'Gemini'를 입력합니다.
        
    - 'Create new gate'를 클릭합니다.
        
5. **핫키 설정**:
    
    - 'Hotkey' 설정에서 'Easy Gate'의 'List All' 기능을 선택합니다.
        
    - 단축키(예: `Ctrl+Shift+G` 또는 `Cmd+Shift+G`)를 설정합니다.
        
6. **플러그인 실행**: 설정한 단축키를 누르거나, 좌측 리본 메뉴의 Gemini 아이콘을 클릭하여 이지게이트 플러그인을 실행합니다.
    
    - 로그인이 필요한 경우, 해당 창에서 로그인합니다.
        

7. 마무리 및 이벤트 안내

이지게이트와 티보드 폼즈를 활용하여 옵시디언에서 다양한 노트를 생성하는 방법을 소개하며, 구독자 이벤트를 안내합니다.

1. **프로그램 조합의 중요성**: 이지게이트와 티보드 폼즈 같은 프로그램을 조합하면 초보자도 필요한 노트를 쉽게 생성할 수 있습니다.
    
2. **구독자 이벤트**: 영상을 보고 따라 해본 후 사용기를 댓글로 남기면 추첨을 통해 플러그인을 이메일로 전송해주는 이벤트를 진행합니다.
    
3. **이벤트 기간**: 12월까지 진행되며, 이후에는 공유되지 않을 예정입니다.
    
4. **함께 공부하기**: 12월까지 제공되는 옵시디언 플러그인을 활용하여 함께 옵시디언을 공부하자는 제안을 합니다.
